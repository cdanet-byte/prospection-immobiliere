# ImmoProspect

Maquette interactive d’un logiciel de prospection immobilière.

> **Radar Baud** (dossier [`radar/`](radar/README.md)) : l'outil réel de détection de biens à fort potentiel de vente autour de Baud (56150), 40 km, avec valorisation sur ventes réelles. La maquette ci-dessous est un CRM de démonstration avec des données fictives.

## Fonctionnalités

- Tableau de bord commercial
- Gestion et recherche des prospects
- Pipeline Kanban
- Catalogue de biens
- Tâches interactives
- Création de prospects

## Lancer

Ouvrez `index.html` dans un navigateur, ou activez GitHub Pages depuis les paramètres du dépôt.
